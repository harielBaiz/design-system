# Spacing, radius and control size

4px base. Every margin, padding and gap should use a token.

export const Bar = ({ name, px }) => (
  <div style={{ display: 'flex', alignItems: 'center', gap: 16, margin: '6px 0' }}>
    <code style={{ width: 120, fontSize: 12 }}>{name}</code>
    <div style={{ width: `var(${name})`, height: 16, background: 'var(--text-3)', borderRadius: 2 }} />
    <span style={{ fontSize: 12, color: 'var(--text-3)' }}>{px}</span>
  </div>
);

## Control size

Shared by Input and Button so they align in a row.

| Token | px | Name |
|---|---|---|
| `--size-100` | 28 | xs |
| `--size-200` | 32 | sm |
| `--size-300` | 40 | md (default) |
| `--size-400` | 48 | lg |
| `--size-500` | 56 | xl |
