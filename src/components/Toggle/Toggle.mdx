# Toggle

Switch control for turning a setting on or off.

<Primary />
<Controls of={ToggleStories.Default} />

## Usage

A toggle works like a light switch: the effect is **immediate**. A checkbox is different, because its choice is only confirmed later by a Save or Submit button.

### When to use

- A setting whose effect applies as soon as it changes (dark mode, reduce motion, show insights).

### When not to use

- The change isn't applied until the user confirms: use Checkbox.
- Choosing between two named options: use Radio or a segmented control.
- Inside a form that has a submit button.

### Best practices

- Write the label as the **thing being turned on**, not an action: "Dark mode", not "Turn on dark mode".
- Show the result right away. If it can fail, say so and put the switch back.
- Keep the label on the same line as the switch.

## Accessibility

- It is a `<button type="button" role="switch">` with `aria-checked`, so screen readers say "switch, on" or "off". Space and Enter toggle it.
- The label is tied through `htmlFor`, so clicking it toggles the switch.
- `aria-describedby` links the description and messages.
- The track has a 2px border at 3:1 contrast or better, and a 2px focus ring.
- A mixed (indeterminate) state is **not** supported: `role="switch"` has no mixed value. Use an indeterminate Checkbox for a parent control.
- Motion respects `prefers-reduced-motion`.

## API

<Controls of={ToggleStories.Default} />

`checked` / `defaultChecked`, `onCheckedChange(checked)`, `label`, `hideLabel`, `description`, `messages`, `size`, `showIcon`, `disabled`. Other native `<button>` attributes are forwarded. The ref points at the button.
